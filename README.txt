BO DIGITAL GSP — v36.0.0

FOCO DESTA VERSÃO
Usabilidade operacional para vigilantes em campo, com menos digitação repetida, feedback imediato de campos condicionais, progresso de preenchimento, acesso rápido a rascunhos/offline e validação obrigatória alinhada ao NEXO.

ARQUIVOS PRINCIPAIS ALTERADOS NESTA VERSÃO
- app.js
- styles.css
- index.html
- service-worker.js

BACKEND
- google-apps-script.gs permanece compatível com API v6.3.0 / schema compact-t.
- Não é necessária nova implantação do Apps Script apenas para atualizar a v36.

PUBLICAÇÃO NO GITHUB
